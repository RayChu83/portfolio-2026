# Ray Chu's Side Projects

## Syllabus to Calendar

Tech: Next.js, TypeScript, Supabase, LangChain. Live at https://syllabustocalendar.com. It is a personal project that turns college syllabus PDFs into Google Calendar events.

- Built an application used by 45 students that automates manual calendar entry. An LLM parses uploaded PDF syllabi to extract student deadlines, which sync to their Google Calendar.
- Cut AI parsing costs by 20–30% by preprocessing raw PDF-extracted text before sending it to the LLM, which directly reduces input tokens on every uncached request.

## Founders Club @ Hunter College

Tech: Next.js, TypeScript, Supabase. A website for the Founders Club, a student organization at Hunter College.

- Spearheaded the end-to-end development of the website for the 50-student organization. It displays upcoming events and handles registration, and has supported a total of 7 hosted events.
